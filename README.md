# ⚡ PowerPulse

PowerPulse is a full-stack web application designed to help users stay informed about power outages in their area. It provides information such as the outage reason, affected area, current status, and estimated restoration time.

## 🚧 Current Progress

### Frontend
- PowerPulse branding
- Login and registration pages
- Login/Register form switching
- Floating label input design
- 10-digit mobile number validation
- Minimum 8-character password validation
- Confirm password validation
- Dashboard UI
- Area-based outage search

### Backend
- Python Flask backend
- REST API integration
- Frontend–backend communication
- MySQL database connectivity
- User registration API
- Outage information API

### Database
- `powerpulse` MySQL database
- `users` table
- `outages` table
- Outage information stored and retrieved from MySQL
